# 🌴 Jazan Smart Farm v2.0
مشروع ري ذكي متكامل لمنطقة جازان يجمع بين إنترنت الأشياء والذكاء الاصطناعي.

## 🚀 التوجه المستقبلي (Roadmap)
* [ ] **المرحلة 1:** ربط النظام بشبكة Wi-Fi لإرسال تنبيهات مباشرة للجوال.
* [ ] **المرحلة 2:** دمج حساسات جودة التربة (NPK) لقياس نسبة الأملاح والأسمدة.
* [ ] **المرحلة 3:** استخدام تعلم الآلة (Machine Learning) للتنبؤ بحاجة المحاصيل بناءً على حالة الطقس في جازان.

## 🛠️ المكونات التقنية
| القطعة | الوظيفة |
| :--- | :--- |
| Arduino Uno | العقل المدبر |
| Soil Moisture Sensor | قياس رطوبة الأرض |
| Relay Module | التحكم في مضخة المياه |
